接口仅监听 127.0.0.1，默认关闭。请求需携带 Bearer 令牌；重置后旧令牌立即失效。工作台保持打开时接口可用。

请求示例

GET /api/v1/profiles列出全部环境
POST /api/v1/profiles创建或更新环境
POST /api/v1/browser/start启动环境 · 请求体 {"id":"环境 ID"}
POST /api/v1/browser/stop停止环境 · 请求体 {"id":"环境 ID"}
POST /api/v1/profiles/batch-edit批量修改所选字段
PATCH /api/v1/profiles/{id}部分更新；省略字段保留
DELETE /api/v1/profiles/{id}删除已停止环境及浏览数据
GET /api/v1/browser/tabs?id=环境ID列出标签页，index 从 0 开始
POST /api/v1/browser/navigate打开网址 · {id, url, tab?}
POST /api/v1/browser/click 或 fill操作网页 · {id, selector, value?, tab?}
POST /api/v1/browser/evaluate网页 JavaScript · {id, expression, tab?}
GET /api/v1/browser/screenshot?id=环境ID返回 PNG，可加 fullPage=true
GET / POST /api/v1/browser/cookies读取 / 导入 Cookie

独立环境，真实边界
Orbit 使用本机 Chromium 浏览器和独立用户数据目录，隔离 Cookie、缓存、历史记录与本地存储，并通过浏览器调试协议设置 UA、语言、时区、视口及配色。
Camoufox 环境提供原生指纹配置：设备参数、屏幕、Canvas 读取保护、WebGL、音频、字体、WebRTC、定位与媒体设备。Chrome / Edge 环境保留基础隔离。两种内核各用独立数据，不保证所有网站上的指纹一致或不可关联；没有云同步、团队权限、内置代理采购或 RPA 服务。
导出的环境配置可能含代理密码；Cookie 也可能包含登录凭据。请只在可信位置保存和分享。
