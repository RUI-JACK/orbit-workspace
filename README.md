# Orbit 环境工作台 1.9.4

本地多浏览器环境管理器。双击桌面「Orbit 环境工作台」启动，无需 Node.js 或命令行。启动网址留空时默认打开 Google 搜索首页；自定义网址优先。

[下载最新 Windows 安装包](https://github.com/RUI-JACK/orbit-workspace/releases/latest) · [程序更新清单](https://github.com/RUI-JACK/orbit-workspace/releases/latest/download/update.json)

## 从源码构建

Windows x64，Node.js 24.21.0 或兼容的 24.x 版本。运行 `npm ci`，然后运行 `npm run prepare:resources` 下载并校验官方内核、固定指纹模型与更新助手运行库，最后运行 `npm run installer`。开发运行使用 `npm start`。大型上游二进制不放入 Git 仓库，来源及许可证见 `THIRD_PARTY.md`。

## 1.9.4 GitHub 版本发布与更新

程序默认更新地址为 `https://github.com/RUI-JACK/orbit-workspace/releases/latest/download/update.json`。旧的空地址首次迁移到此地址，保留自定义地址和自动更新开关。首次安装下载完整 EXE，程序更新下载 Ed25519 签名的代码 ZIP；内核更新仍走官方兼容频道。维护者发布流程见 `docs/UPDATES.md`。

1.9.2 及更早版本请先下载本次 EXE 覆盖安装一次：旧版 Electron 下载接口不能正确处理 GitHub 跳转，1.9.3 已修复。后续版本可通过程序内的签名代码更新升级。

1.9.4 收紧更新包文件范围，并在签名前用客户端相同规则解压预检，防止额外资源文件导致更新被拒绝。

## Windows 安装包

运行 `npm run installer`，使用当前源码和前端重新打包，然后生成 `releases/installers/Orbit-Setup-1.9.4-win-x64.exe`。安装包内置狐狸内核和更新助手，提供中英文向导、当前用户安装、安装目录选择、桌面与开始菜单快捷方式及卸载入口。升级或卸载时检查目标目录中的运行进程，要求先关闭程序，不强制结束环境；卸载保留工作台数据。

分发时只发送安装 EXE 与安装说明即可。发布构建排除环境数据、备份、验证材料和更新签名私钥；不附带发布者的代理、Cookie 或扩展库。使用者说明见 `docs/INSTALL.md`，发布文件夹同时生成 SHA-256 和版本清单。当前没有 Windows 发布者代码签名。安装构建在 Windows 上执行，构建工具 electron-builder 固定版本并记录在锁文件中。

## 1.9.1 视频全屏尺寸修复

狐狸内核不再固定网页内部视口尺寸，保留配置的初始外窗口和屏幕参数。网页全屏时视口随真实浏览器窗口扩大，退出后恢复正常窗口；每次启动都会移除旧身份中的内部视口尺寸限制，无需删除环境或重建指纹。已在本机 2880×1800、200% 缩放下验证真实视频播放、全屏覆盖和退出恢复。

## 1.9.0 失败截图与自动重试

每个网页操作步骤可设置额外重试 0–5 次、间隔 100–60000 毫秒；默认不重试。只重复失败步骤，成功后继续，停止任务会取消重试等待。进度与执行记录显示实际尝试和重试次数。环境准备失败或任务页已关闭时不自动重启环境。

最终失败后默认截取任务页的可见区域，可在任务中关闭。截图用 Windows 本地加密保存，在执行记录中预览、缩放或主动另存为 PNG；保留最多 50 张、合计 100 MB，清除记录或淘汰记录时清理对应文件。任务页不存在或截图失败会明确记录，截图本身不随完整环境备份恢复。详见 docs/OPERATIONS.md。

## 1.8.0 网页操作录制与元素点选

自动化编辑器增加录制环境选择、开始/停止录制、步骤导入、撤销，以及每步的「点选」按钮。普通网页的点击、输入、勾选、单选下拉和 iframe 元素可以转成可编辑步骤；连续输入自动合并，点选会拦住这次点击，Esc 可取消。支持 Chrome / Edge 与 Camoufox，录下的步骤可跨内核回放。密码框与文件上传跳过，录制草稿只在内存保留，加入步骤并保存任务后才进入现有加密配置与完整备份。

录制只覆盖选定的标签页，不包含系统界面、浏览器工具栏、新标签页与 Shadow DOM。执行前需检查步骤，页面布局、登录状态或元素变化仍可能导致回放失败。具体用法见 docs/OPERATIONS.md。

## 1.7.0 窗口同步、可视化步骤与定时任务

侧栏「窗口同步」选择一个主环境和多个跟随环境，支持网页点击、输入、滚动、勾选、单选下拉和跳转，支持暂停继续。Chrome / Edge 与 Camoufox 可互相同步；按元素定位，适用于结构相同的网页，只同步选定的标签页，浏览器工具栏及系统弹窗不在范围内。

「自动化与定时」通过表单添加和排序网页操作步骤，支持自动启动环境、专用任务标签页、停止、失败步骤记录，以及单次、间隔、每日定时。工作台需保持运行，关闭期间不补跑；任务步骤加密保存并纳入完整备份，恢复后定时默认暂停。无需启用本地 API。具体用法和限制见 docs/OPERATIONS.md。

## 1.6.0 程序与内核自动更新

设置页新增更新检查、后台下载、取消下载、程序重启安装、内核空闲切换与回退。程序代码更新包通过 Ed25519 签名、SHA-256、文件树和版本校验；同一 Electron 版本内自动升级代码与资源，运行库改变时提示安装完整程序包。更新助手在旧进程退出后替换文件，验证新版界面启动，失败恢复原版。内核使用 Camoufox 官方稳定发布并进行兼容检查、临时浏览器启动测试；现有环境运行时不会替换内核。当前没有程序发布服务器，程序更新地址留空，不宣称已接收在线程序更新。发布工具与私钥说明见 docs/UPDATES.md。

## 1.5.1 启动耗时与失败诊断

侧栏「启动诊断」记录代理端口连接、出口地区查询、环境准备、浏览器启动、首页加载五阶段。分别显示窗口可用与全部启动页 DOM 就绪的耗时，首页失败保留已打开的浏览器。端口或地区检查失败停止启动，不回退直连。支持 Chrome / Edge 与 Camoufox、实时进度、按环境和异常筛选、处理建议、历史保留（每环境 10 条、总计 100 条）和清除。

代理端口探测为最多 3 秒的 TCP 检查，不代表认证或出口通过；下一步仍通过该环境的代理重新查询地区。首页测量每页最多等待 20 秒，不包含图片及后续后台请求。记录随本机加密工作台状态保存，不写入代理凭据、令牌、原始驱动日志或网页地址。此版本增加诊断，不承诺提升网站响应速度。

## 1.4.7 环境启动加速

复用工作台已读取的显示器尺寸，Windows x64 通过本地系统 API 查询和设置 CPU 亲和性，避免反复启动 PowerShell。保留原有 CPU 数量、随机核心选择、启动锁与启动结束 / 失败后的主进程恢复；原生组件不可用时回退原启动器。Chrome 与 Camoufox 共用启动锁，避免继承到另一环境的临时 CPU 分配。代理地区仍在每次启动时通过该代理重新查询，不使用过期地区缓存。

## 1.4.6 地址栏 Google 搜索

Camoufox 的普通和隐私窗口默认搜索引擎设为 Google Search，使用 HTTPS GET 搜索并保留 UTF-8 查询词。移除内核原有的 None 占位引擎（指向 127.0.0.1），已有环境下次启动自动迁移；新标签页仍打开 Google 首页。

## 1.4.5 Google 新标签页

在环境中点击新标签页按钮或按 Ctrl+T，默认打开 https://www.google.com/。Camoufox 使用内核的新标签页设置；Chrome / Edge 将内置新标签页导航到 Google。自定义启动网址、网站正常打开的链接、扩展欢迎 / 设置页和明确创建的 about:blank 页面保持原行为。

## 1.4.4 Camoufox 扩展初始化修正

允许扩展通过原生 tabs.create 打开欢迎页、设置页和登录页。Camoufox 默认禁止扩展创建新标签页，可能让 AdGuard 等扩展在首次初始化时抛出 Rejected by Camoufox，导致弹窗一直转圈。已有环境下次启动时生效，保留扩展、登录数据和原有设备参数。本版本以已安装的 1.4.2 为基础，仅包含本次扩展修复；此前未发布的 Chrome 指纹调试改动未部署。

## 1.4.2 Chrome 扩展安装修正

Chrome / Edge 环境不再使用启动库默认的 `--disable-extensions`，允许用户在各自的独立环境中安装和使用扩展。安装与权限确认由浏览器正常处理。已有环境在下次启动时生效，不修改其他浏览器或系统策略。Chrome 扩展与 Camoufox / Firefox 附加组件属于不同格式。

## 1.4.1 启动提示修正

Chrome / Edge 的受控窗口使用 `--test-type=` 标记，避免 SOCKS5 模式由 Playwright 自动加入的 `--host-resolver-rules` 触发顶部启动警告。解析规则仍保留。这是受控窗口提示的处理，不表示该参数获得 Chrome 官方支持，也不改变其他浏览器参数。已用真实 Chrome 155 验证 SOCKS5 远程域名解析、窗口显示和 Cookie / 本地存储重开保留。

## 两种内核

- 新建环境默认选择 **Camoufox 原生指纹内核**，基于 Firefox 156.0.1-beta.36。
- 已有 Chrome/Edge 环境保持原样。编辑时可切换内核；两种内核各自保存登录数据，切换不会迁移 Cookie。原数据保留，切换回来仍可使用。也可以复制配置后在新环境中使用新内核。
- 新环境首次启动生成设备配置并保存，之后重用。更多操作中的「下次启动重新生成指纹」会更新设备种子，不删除登录数据；网站可能要求重新验证登录。

## 指纹配置

新建环境默认读取工作台所在显示器的当前尺寸和系统缩放。屏幕宽高使用浏览器的逻辑像素，与设备像素倍率一起对应显示器物理分辨率；已有环境保留保存的数值。

Camoufox 环境支持系统类型、Firefox UA、CPU 逻辑核数、触摸点数、屏幕尺寸/色深/像素倍率、窗口尺寸、Canvas 原生读取保护、WebGL 设备参数/禁用、音频种子和采样率、字体白名单、WebRTC 模式、网页定位、媒体设备数量以及 DNT/GPC。

默认启用 Canvas 读取保护、关闭 WebRTC、阻止网页定位和真实摄像头/麦克风权限。可编辑需要的参数。代理定位或 WebRTC 代理模式需要有效的代理出口数据。自定义 GPU 必须是内核支持的 Vendor/Renderer 配对；缺失字体无法仅凭名称生成。Firefox 未提供 navigator.deviceMemory 时保持缺省行为，不伪造一个非原生 API。

启动环境后，更多操作 → **检测实际指纹**：从当前环境的新空白页读取 UA、CPU、Worker、屏幕、时区、Canvas/音频摘要、WebGL 等。检测不访问外部指纹网站。Canvas 保护可能使图像读取受限或随机化，因此不承诺 Canvas 摘要跨页面固定。字体探测使用 Canvas 文本宽度，会受读取保护影响。

## 代理与数据

填写环境代理后，每次启动自动经该代理查询 ipwho.is 出口地区并同步语言、时区，无需勾选。查询失败会停止启动，保留原设置，不回退直连查询。该功能不读取系统代理。多语言国家的语言按国家推测，IP 定位可能不准确；轮换代理也可能在查询和浏览请求之间换出口。

支持环境创建、编辑、复制、删除、分组、标签、搜索、批量启动停止、配置导入导出和 Cookie 管理。复制只复制配置，不复制登录状态；新副本生成新的音频种子和设备配置。配置导出可能包含代理凭据。

工作台数据：`%APPDATA%\OrbitLocalWorkspace`，配置经 Windows DPAPI 加密；浏览数据按环境及内核隔离。删除环境会删除它自己的浏览数据。原有环境数据不因程序升级而迁移或清除。

## 本地 API 与批量编辑

设置与说明中启用本地 API 并保存，到侧栏「本地 API」复制令牌。默认关闭，只绑定 127.0.0.1；需 Bearer 令牌，不接受网页 Origin 请求。令牌保存于 DPAPI 加密工作台配置中，可重置；旧令牌立即失效。退出工作台会关闭接口。端口冲突时保留之前的设置和服务。

接口支持环境 CRUD、部分更新、批量编辑、启动/停止、标签页列表、打开网址、点击、填表、网页 JavaScript、Cookie 导入导出和 PNG 截图。接口返回的配置不包含代理密码、设备身份配置或令牌。常规页面不显示令牌；复制时系统剪贴板不可用会打开手动选择窗口，关闭后清空显示。详细接口和 PowerShell / Python 示例在 `docs/LOCAL_API.md`，程序内可点击「接口说明与示例」。

在环境列表勾选多个停止中的环境 → 批量编辑，只修改勾选字段。分组、标签（替换/追加/移除）、备注、启动页、语言、时区、UA、视口、配色及 Camoufox 部分原生参数可直接批改；完整原生设置可从已有 Camoufox 环境取模板。模板不复制生成的设备身份或音频种子，不切换内核。任一环境运行中或参数无效时，整批拒绝，不部分保存。

## 完整备份与代理池

设置与说明 → 创建完整备份：先停止全部环境，设置至少 8 位的独立备份密码，保存 `.orbitbackup`。备份包含环境配置、指纹身份、两种内核的完整浏览数据、代理池及设置清单；不包含程序和内核二进制。使用流式 ZIP 和 AES-256-GCM 加密，密码由 scrypt 派生，不保存密码。

从备份恢复：先停止全部环境，输入密码并选择文件。校验通过后恢复为新 ID 的新增环境，名称附加「恢复」，保留原环境。代理按地址及认证信息去重；当前浏览器路径和本机设置保留。Chrome / Edge 的部分加密数据绑定 Windows 账户或浏览器运行环境，跨电脑不能保证登录状态直接可用；网站也可能要求重新验证。备份密码丢失无法恢复。

代理管理 → 批量导入代理：每行一个 URL（支持 URL 编码的认证信息），或 `主机:端口:用户名:密码`，无协议按 HTTP 处理。支持去重、批量出口检测（每批最多 100 条、并发 3）、一对一或轮流分配给停止中的环境，环境编辑页也可从池中填入代理。检测结果记录出口 IP、地区、时间及整个查询耗时，不是线路延迟基准。删除池中条目不修改已经分配给环境的连接；不自动切换出口、不定时检测。

## 实际边界

指纹配置不保证所有网站上的身份一致或不可关联。GPU 模拟不等于实际拥有该硬件，CPU 报告值也不改变物理算力；字体、Emoji、TLS、WebGPU、浏览器版本与底层 OS 仍有边界。媒体设备数量不会创造可用的摄像头或麦克风。当前没有云同步和团队权限；本地自动化、录制与窗口同步见前述版本说明。

仅配置工作台启动的浏览器，不更改 Windows 或 Claude Code 等命令行程序的系统环境。Camoufox 原生组件及模型约 2.8 GB，随程序放在 `resources/native-engine`；请保留完整程序文件夹。

## 1.5.0 扩展统一管理

侧栏「扩展管理」支持 Camoufox / Firefox XPI 扩展库、本地清单及 SHA-256 校验、从现有环境收录扩展、批量安装与移除、版本更新及浏览器启用/禁用/拒绝加载状态。运行中的环境需要先停止。仅管理主动分配的扩展，保留其他扩展和扩展本地数据；浏览器自行更新的版本会保留，收录当前版本后可继续管理。完整加密备份包含库中扩展包、环境分配及管理记录；恢复时重映射 ID。普通 JSON 配置只携带本机可解析的库引用，不携带扩展包。

当前只支持 Firefox WebExtension 的 XPI 包，浏览器自行验证签名及兼容性；库导入只检查包结构、清单和校验值，不代表签名认证。状态读取浏览器本地记录，不检测扩展后台脚本异常、第三方服务或登录状态；Chrome 扩展集中管理尚未实现。
