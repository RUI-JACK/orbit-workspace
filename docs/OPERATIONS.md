# 窗口同步与自动化

## 窗口同步

先启动需要操作的环境，在它们对应序号的标签页打开网页，再进入侧栏「窗口同步」。选择主环境和 1–20 个跟随环境，点击「开始同步」。标签页序号从 0 开始；默认使用第一个标签页。默认将跟随页对齐到主页面，并跟随主页面后续的 HTTP/HTTPS 跳转。

支持网页元素点击、输入、单选下拉、复选框/单选框、常用导航按键、滚动和 iframe 内对应结构的操作。按元素定位，不依赖窗口像素坐标；各窗口尺寸可不同，但网页结构应相同。跟随失败会在状态区累计并提示，后续操作仍继续。可随时暂停、继续、停止。停止或暂停后尚未执行的排队操作会跳过；已发出的网页操作可能正在完成。

密码框内容默认不复制，可主动勾选开启。输入只参与实时转发，不写入同步历史。会话只在本次工作台运行期间存在，重开程序不会恢复。关闭主标签页或从工作台停止参与环境会结束同步。

仅控制开始时选定的标签页，不跟踪用户切换标签。地址栏、创建/关闭标签页、浏览器工具栏、扩展弹窗、系统文件对话框、文件上传、拖拽、画布和 Shadow DOM 等特殊组件暂不支持。网页结构变化或不同账号看到不同布局时，可能无法定位对应元素。

## 可视化步骤编辑

在「自动化与定时」新建任务，输入名称、选择环境，再添加并排序步骤：打开网页、点击、填写文本、按键、选择下拉值、设置勾选、等待时间、等待元素可见。每步可设置超时。步骤使用 CSS/Playwright 元素选择器；例如 `#search`、`input[name="q"]`，无需写 JavaScript 脚本。

任务按选择顺序执行环境，每个环境使用专用的新标签页。可自动启动未打开的环境；勾选「完成后关闭本任务启动的环境」只关闭这次自动启动的环境，已打开的环境保留。默认遇到失败停止后续环境，也可以关闭该选项继续执行其他环境。同一时间只运行一个任务。

点击「停止执行」会取消后续步骤并关闭任务正在使用的专用页，原有标签页保留。历史保留最近 50 次的环境、步骤和结果，不记录填写的文本、网页源码或驱动堆栈。任务内容包括输入值，由工作台现有的 Windows 本地加密机制保存。

同一环境不能同时进行窗口同步和自动化。执行中不能修改任务或编辑其环境配置；被任务引用的环境需要先从任务中移除或删除任务，才能删除该环境。更新安装和完整备份需要等待任务及环境停止。

## 定时

支持指定时间执行一次、每隔若干分钟、每天本机时间执行。设置页显示当前系统时区与下次执行时间；可单独暂停或启用任务定时。

工作台必须保持运行，不会注册系统服务或让电脑自动开机。关闭期间错过的任务不会补跑：已错过的单次任务会暂停并留记录，重复任务重新计算未来执行时间。工作台运行时如果其他任务正在执行、环境不可用或正在同步，本次跳过并留记录，不排队堆积。

完整加密备份包含任务步骤。恢复时新增任务并关联到本次恢复出的新增环境，所有恢复任务的定时默认暂停，需要检查后手动开启。运行中的同步会话和任务不属于恢复内容。

## 录制网页操作与点选元素（1.8.0）

编辑器中选择「操作环境」与标签页序号，先启动环境并打开网页。点击「开始录制」后，在该标签页进行操作；完成后回到工作台点击「停止」。录制结果可替换当前步骤或追加到末尾，也可撤销上次导入。检查步骤并点击「保存任务」后才用于执行和定时。编辑器底部也提供保存按钮。

录制包括初始网址、点击、填写文本、勾选、单选下拉、部分按键和后续网页跳转。连续输入同一个字段会合并成一次填写，最多 100 步；密码框和文件上传跳过。录制期间同一环境不能同步操作或运行自动化任务。

每个元素步骤旁的「点选」按钮会打开选定网页的元素选择模式。移动鼠标查看高亮，点击目标元素即可填入选择器与 iframe 路径；此次点击不会触发原网页按钮或链接。按 Esc 或工作台的「停止」取消。点击后返回工作台检查结果，其他字段和任务步骤保持原值；可撤销上次点选。iframe 路径随步骤保存、回放和完整备份恢复。

录制草稿和临时元素选择只在本次运行的内存中保留，关闭程序后清除；需要主动导入步骤并保存任务。录制模式对 iframe 标准文本框补全点击后的焦点，以兼容 Camoufox 的输入行为。录制停止后会撤除监听和选择覆盖层。

当前只覆盖选定标签页内的普通 DOM 与 iframe，不包括 Shadow DOM、画布、拖拽、文件上传、系统弹窗、浏览器工具栏和新标签页。回放依赖页面结构与状态，运行或启用定时前应检查步骤；必要时增加「等待元素可见」或等待时间。当前编辑器还不包含条件分支、循环、脚本步骤或验证码处理。

## 失败重试与截图（1.9.0）

每个网页步骤提供「每次超时」「失败重试次数」「重试间隔」。重试次数指额外尝试次数，0 表示关闭；设为 2 时最多执行 3 次。允许额外重试 0–5 次，间隔 100–60000 毫秒。旧任务默认不重试，录制出来的新步骤同样默认不重试。

只重试当前失败步骤，成功后继续后续步骤，不会从头重跑。打开网页时，HTTP 4xx/5xx 也按失败处理。等待时间步骤不需要重试。任务页已关闭时不再尝试，环境启动和代理准备失败也不自动重启环境。点击或按键重复执行可能再次提交操作，按步骤需要开启。运行区显示当前尝试次数、等待重试或正在截图的状态，点击停止会取消等待和后续尝试。

任务的「最终失败时保存当前页面截图」默认开启，可关闭。只在该环境步骤最终失败后保存一次，不截取中间的失败尝试；重试后成功或用户停止不产生该步骤的失败截图。截取任务标签页的可见区域，单张上限 8 MB，最多等待 5 秒。页面不存在、已关闭、超限或无法保存时，执行记录会显示原因，不伪造成功截图。

截图可能包含网页上的可见信息。文件保存在工作台数据目录的 `automation-screenshots` 下，沿用工作台的 Windows 本地加密；不会自动生成明文图片。执行记录中的「查看失败截图」支持适应窗口、原始尺寸和主动另存为 PNG。记录只保存环境、步骤、次数与截图引用，不保存输入文本或驱动堆栈。

最多保留 50 张、合计 100 MB 的加密截图，超出后删除较旧的文件，旧记录显示「截图已清理或不可用」。清除执行记录会一并删除本程序的加密截图，不影响主动另存的 PNG。任务执行中不能清除记录。截图及执行历史不随完整环境备份恢复；任务的重试参数和截图开关会正常恢复，定时仍默认暂停。

实现基于 [Playwright 的网页控制接口](https://playwright.dev/docs/api/class-browsercontext)。
