# 程序与内核更新

设置与说明 → 程序与内核更新。默认后台检查并下载兼容更新，启动后等待 10 秒检查，此后每 6 小时检查；检查时间持久保存，重开程序不会重复下载。

程序更新使用公开仓库 `RUI-JACK/orbit-workspace` 的 GitHub Releases，固定地址为 `https://github.com/RUI-JACK/orbit-workspace/releases/latest/download/update.json`。默认自动填写；旧版空地址首次升级时补齐，保留自定义地址和自动更新开关，之后主动清空地址也会保留。可以关闭自动检查或自动下载，手动检查、下载和安装。

## 更新行为

- 程序：同一 Electron 版本内自动更新代码与配套资源；运行库版本改变时提示安装完整程序包。下载 ZIP 后校验 Ed25519 发布签名、SHA-256、大小、包内版本和文件路径。所有环境停止后可「安装并重启」；自动模式在下次打开工作台时安装。后台助手等待原进程退出，备份被替换的文件并启动新版。新版界面与本地数据成功加载后才确认；启动检查失败恢复上一版程序和更新前的本地数据配置。
- 内核：只读取 `daijro/camoufox` 的 GitHub 最新稳定发布，使用官方 Windows x64 资源与 SHA-256。测试发布不自动安装。当前仅允许 Firefox 156.0.1、接口 1 的兼容更新；跨版本变化需先发布兼容程序。下载后用独立临时环境检查实际启动、脚本通信、语言和时区，全部环境停止后切换。旧内核保留，可手动回退。下载或自检失败保留当前内核。
- 更新通过系统网络联网，不读取各环境的代理密码，不强制关闭运行中的环境，不替换用户的配置、Cookie、扩展或登录目录。下载中可取消。磁盘需要容纳下载包、解压文件与旧版备份，内核包可能超过 1 GB。
- Google 启动页、新标签页与地址栏搜索设置会重新应用到新版内核；不会用旧版 `camoufox.cfg` 整文件覆盖新版本。
- 本机 Chrome / Edge 继续由各自官方更新服务管理，工作台不代替它们的更新器。
- Windows 更新助手随程序安装，使用独立、带原始签名的 Node.js 运行库，不依赖系统 PowerShell。遇到 EPERM / EACCES 会保留旧版并显示目录权限或安全软件提示；不会自动修改安全软件和系统策略。

本机验证范围：检查官方版本、签名/摘要校验、取消下载、恶意 ZIP 拒绝、内核独立启动自检、运行状态保护和设置持久化已经通过。使用独立测试安装目录完成签名代码更新包的实际替换、重启与界面健康确认；故意启动失败的新版也已验证恢复旧版程序及加密配置。当前官方稳定内核与已安装版本相同，未进行新官方内核的实际升级。未配置发布地址时不会触发程序自动替换。

当前官方稳定源：https://github.com/daijro/camoufox/releases/latest

## 发布程序新版本

项目目录 `.update-signing/private.pem` 是本机生成的 Ed25519 私钥，权限限定给当前 Windows 账户；`update-trust.json` 是随程序打包的验证公钥。私钥不进入程序包或更新 ZIP。请备份私钥，勿上传、分享；丢失后需要通过可信安装包更新验证公钥。

1. 修改 `package.json` 与 lockfile 的程序版本，更新 `docs/RELEASE_NOTES.md`，完成测试，运行 `npm run installer`。
2. 运行：

   ```powershell
   npm run release:prepare
   ```

3. 将源码提交并推送到 GitHub，创建对应 `v版本号` 标签。先创建该标签的草稿 Release，上传完整安装 EXE、`releases/update.json`、`releases/版本/Orbit-版本-win32-x64.zip`、安装说明与 SHA-256 校验文件。确认资源全部上传并核对摘要后，再发布草稿。
4. 更新清单内的 ZIP 地址固定到对应的 `v版本号` 资源，程序中的入口地址则始终使用 `/releases/latest/download/update.json`。不要将 Release 网页或 EXE 地址填成更新清单地址。不要修改已经签名的清单或 ZIP。

私钥必须由原维护者在本机保管，Git 中只包含验证公钥；从公开源码克隆的其他人不能签发原频道更新。自行分发衍生版本需要自行生成密钥并替换公钥和发布仓库配置，不要把私钥提交到 Git、Release 或安装包。

程序和浏览器内核可以分别发布；内核兼容范围改变时，需要同步升级程序的驱动与兼容检查。更新回退只保留一段自动恢复流程，不代替「完整环境备份」。
