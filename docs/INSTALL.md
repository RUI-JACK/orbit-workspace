# Orbit 环境工作台：安装与首次使用

适用系统：Windows 10 / 11，64 位 x64 电脑。安装包已包含狐狸浏览器内核和运行库，无需安装 Node.js、Python 或开发工具。可选的 Chrome / Edge 环境需要电脑上已有对应浏览器。

1. 下载 Orbit-Setup-版本号-win-x64.exe，双击打开。
2. 选择中文，按安装向导选择安装目录并安装。默认安装到当前用户目录，无需管理员权限。建议至少预留 8 GB 可用空间，后续每个浏览器环境还会占用额外空间。
3. 安装完成后，从桌面的「Orbit 环境工作台」打开。
4. 点击「新建环境」，选择内置狐狸内核，填写名称。需要代理时填写自己的代理地址和认证信息，再保存、启动。
5. 默认首页和新标签页为 Google。访问是否成功取决于你所在网络和代理，软件不附送代理、账号或网络线路。

首次启动是空工作台，不包含发布者的环境、Cookie、账号、代理或扩展库。每位使用者自行建立环境；需要迁移时使用程序内的加密备份和恢复功能。

## 升级与卸载

覆盖安装前，先关闭工作台及其打开的浏览器环境。安装器会检查目标安装目录的运行进程，不会强制结束程序。使用相同安装目录升级；重要数据建议先从程序内备份。

可从 Windows「设置 → 应用 → 已安装的应用」卸载。卸载会移除程序及快捷方式，保留当前用户的环境数据，便于重装。

数据目录：%APPDATA%\OrbitLocalWorkspace。该目录可能包含登录状态与敏感数据，请勿当作安装包直接发送给别人。工作台的本地加密配置受 Windows 账户保护；跨电脑迁移请使用加密备份功能。

## 常见情况

- 程序和安装包目前没有 Windows 发布者代码签名，Windows 可能提示发布者未知或信誉不足。收到不明来源或校验不一致的安装包时不要运行；不要关闭安全软件来绕过恶意软件告警。SHA256SUMS.txt 可用于核对传输完整性，但同一来源的校验文件不单独证明发布者可信。
- 代理连接失败：检查自己的代理程序是否运行、端口和协议是否正确；代理失败不会自动改成直连。
- 没有设置代理：环境使用当前电脑的网络连接；本程序不会自动提供独立 IP。
- 程序默认从 https://github.com/RUI-JACK/orbit-workspace/releases/latest/download/update.json 检查签名更新。也可从 Releases 下载完整安装包覆盖升级。内核在线更新仍需能够访问官方来源，安装本身无需联网下载内核。
- 此工具提供本地环境管理和配置，不保证账号不关联、IP 信誉或平台接受结果。请遵守所用平台的账号规则。

第三方组件、许可证和来源说明保留在安装目录的 resources\THIRD_PARTY.md 与相关组件目录。

本包由 electron-builder 的 NSIS 安装器构建，安装器文档：https://www.electron.build/nsis/ 。
